# Spectral Filtering with VAW

This repository contains the implementation and experiments of **Spectral Filtering with VAW (Vovk-Azoury-Warmuth)** for online learning and control of linear dynamical systems.

The project was developed as part of the graduate course:

**COE 748 — Introduction to Online Control**

## Overview

The main goal of this project is to explore modern approaches in **Online Nonstochastic Control** through:

- Spectral Filtering
- Hankel matrix representations
- Online learning algorithms
- Adaptive prediction in dynamical systems
- Recursive second-order optimization methods

The implementation combines:

- Spectral feature extraction using Hankel matrices and SVD
- Online prediction using the VAW algorithm
- Linear Dynamical System (LDS) simulations
- Sequential learning and filtering techniques

## Topics Covered

- Online Control
- Online Convex Optimization
- Spectral Filtering
- Linear Dynamical Systems (LDS)
- Hankel Matrices
- Recursive Least Squares
- Adaptive Filtering
- State Space Models
- Sequential Prediction

## Objective

This repository aims to provide both:

a practical implementation of spectral filtering using VAW (Vovk-Azoury-Warmuth) algorithm;
and an educational resource for understanding modern online control methods.
